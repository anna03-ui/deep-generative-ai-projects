# Deep Generative AI Projects using GANs

This repository contains implementations of multiple Generative Adversarial Network (GAN) architectures for image generation and image-to-image translation using PyTorch and deep learning techniques.

Implemented GAN models include:

- Vanilla GAN
- DCGAN
- Pix2Pix GAN
- CycleGAN

The projects demonstrate applications of generative AI, computer vision, and deep learning through realistic image synthesis and style transfer tasks.

---

## Features

- Vanilla GAN for basic image generation
- DCGAN using convolutional neural networks
- Pix2Pix for paired image-to-image translation
- CycleGAN for unpaired image translation
- Monet-to-Photo image transformation
- PyTorch-based implementations
- Training visualization and generated outputs
